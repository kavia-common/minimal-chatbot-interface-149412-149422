# Gemini Chatbot Frontend (React + Vite)

Minimal React frontend to send a message to the FastAPI backend and display Gemini's reply.

## Setup
1. Install dependencies:
   npm install
2. Run the dev server (port 3000):
   npm run dev

## Usage
- Type a message and click Send.
- The app POSTs to http://localhost:3001/chat and displays the reply.
- Errors show inline with a Retry option.

## Theme
Ocean Professional: blue primary (#2563EB), amber accents (#F59E0B), modern rounded UI with subtle shadows.
